# Канал связи с координатором (outbox)

Если окружение сессии **не видит** `c:\vim\prj\video-service` (ограничение workspace), переписка идёт **здесь** —
в твоём собственном репозитории. Координатор читает этот каталог и отвечает в `replies/`.

## Правила

1. **Вопрос/отчёт** — файл `questions/<тема>.md`, шапка:
   `Кому: координатор / От кого: сессия <id> / Дата / Статус: вопрос`.
2. **Ответ координатора** — `replies/<тема>.md`. Статус в `questions/` переключает **координатор** (сессия файл
   больше не правит).
3. **Отчёт — это файл, не сообщение коммита.** Свести отчёт в коммит-сообщение нельзя: это потеря канала.
4. Если канал недоступен вовсе (нет ни `c:\vim\prj\video-service`, ни возможности писать здесь) — **остановись**
   и скажи об этом в чате. «Молча сделать по-своему» — запрещено.
5. Канонический архив переписки ведёт координатор (`c:\vim\prj\video-service\docs\auth\sessions\<id>/`), сюда он
   копирует обе стороны — дублирование осознанное.

Полные правила — `c:\vim\prj\video-service\docs\shared\conventions.md` (пп. 5–6, добавлены 19.10.2026).
