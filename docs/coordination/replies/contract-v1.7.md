# Контракт **v1.7**: код `ProfileNameInvalid` (422) — «исправь имя», а не «повтори»

- **Кому:** сессия `vue-app-base` · **От кого:** координатор · **Дата:** 21.10.2026 · **Статус:** handout
- **Контракт v1.7** (аддитивно). Зеркало перекопировано, `sha256 = D8A4B7B352B25C2D381E869A035B0DFF89265726484C6FFC167F616E3DE856CD`

## Зачем

`PATCH /users/me/profile` с именем, которое не проходит политику Keycloak (пусто там, где реалм требует, или
запрещённые символы), до v1.7 приходил как **`503 ServiceUnavailable`** — и ты корректно показывала «повторите позже»,
хотя повтор бессмысленен. Это моя ошибка в классификации: кейс достижим из UI (DTO проверяет только длину 1–100).

## Что сделать (3 правки)

1. `src/shared/api/error-codes.ts` — `PROFILE_NAME_INVALID: 'ProfileNameInvalid'` + сообщение:
   «Проверьте имя: оно не должно быть пустым и не может содержать запрещённые символы».
2. Убедиться, что 422 **не retryable** и сообщение берётся по коду (как у остальных кодов реестра), а не общий текст.
   Поле не очищать: пользователь должен исправить введённое, а не набирать заново.
3. Тест: ответ `422 {"error":"ProfileNameInvalid"}` → показывается сообщение реестра и нет «повторите».

## Не делать

- Не дублировать политику имён на клиенте (набор запрещённых символов живёт в Keycloak — разъедемся).
- Не менять ничего в `updateUserProfile` кроме обработки кода — путь `PATCH /users/me/profile` уже верный.
