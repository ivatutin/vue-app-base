## Осталось (не блокирует закрытие фронта)

1. **Образ контейнера `app` старый** (в нём нет `PATCH /users/me/profile`): `docker compose build app` падает на
   `auth.docker.io` (нет сети из Docker). До пересборки self-service профиля в контейнерном режиме даёт `403`;
   в host-режиме работает. Когда registry доступен — `docker compose build app && docker compose up -d app`.
2. **Вход «телефон + пароль»** — отдельный вопрос `2026-10-20-phone-password-sign-in.md` (v1.7).
3. **Рецепт звонкового канала** (шаг 8) — `2026-10-20-step8-call-ui-done.md`; `host.docker.internal` из Docker недоступен,
   рабочий вариант — второй инстанс `app-dev` в сети compose + `VITE_PROXY_TARGET` у фронта.
4. **Брендинг Keycloak** — бэклог `docs/auth-roadmap.md` § M5 (после брендбука).
