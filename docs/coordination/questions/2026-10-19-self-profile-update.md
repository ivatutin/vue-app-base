# Самостоятельное редактирование профиля: эндпоинта нет — нужен или read-only, или `/users/me/profile`

- **Кому:** координатор
- **От кого:** сессия `vue-app-base`
- **Дата:** 19.10.2026
- **Статус:** вопрос
- **Источник:** живая проверка стенда (вход `user-dev@example.com` → `/account/profile` → «Сохранить»)

## Факт

`PATCH /users/:id/profile` в бэкенде закрыт `@Roles('admin')` (`user.controller.ts:115-116`).
Самостоятельного эндпоинта (`PATCH /users/me/profile`) в контракте **v1.5 нет** — в разделе
Account security есть только `password` / `set-password` / `logout-all` / `contact-change/*`.

Живой прогон (логи `app-backend`):

```
PATCH /api/v1/users/<id>/profile → 401 InvalidToken  (access-токен истёк: TTL 300 с)
PATCH /api/v1/users/<id>/profile → 403 Forbidden     (фронт сам обновил токен и повторил; роли `user` не хватает)
```

`401` — не дефект: сработал refresh-мутекс (ADR-0006), второй запрос ушёл с новым токеном.
`403` — реальный разрыв: страница `/account/profile` в задании описана как «ProfilePage (имя)»,
но прав на запись у обычного пользователя нет: имя меняет только админ.

## Что сделал на фронте (без изменения контракта)

- `/account/profile` остаётся доступной всем авторизованным;
- поля редактируются только при праве `user.update` (`admin`/`manager`, словарь ADR-0004);
- остальным — read-only + подсказка «Имя и фамилию меняет администратор»; кнопки «Сохранить» нет.
  Так пользователь не получает 403 после нажатия.

## Вопрос

1. **Добавить `PATCH /users/me/profile`** (self-service, `@Roles` нет, тело то же `{ firstName?, lastName? }`)?
   Это единственный вариант, при котором пункт задания «ProfilePage (имя)» выполняется для обычного пользователя.
   Если да — фронт переключится одной строкой (`updateUserProfile` → `/users/me/profile`), форма снова станет доступна всем.
2. Или **зафиксировать как есть** («имя меняет администратор»), и тогда я уберу из роадмапа/отчёта формулировку
   про самостоятельное редактирование имени.

Пока ответа нет — оставляю read-only: это соответствует бэкенду и не ломает приёмку остальных пунктов Phase 4.
