# 0009. Дизайн-язык: Inter + нейтральная база с индиго-акцентом

- **Status:** accepted
- **Date:** 2026-06-03

## Context

После ухода с Vuetify ([ADR-0007](0007-ui-stack-migration-from-vuetify.md)) приложение осталось на нейтральной (zinc) палитре shadcn-vue по умолчанию:

- `--primary` ≈ чёрный, `--ring` ≈ zinc — нет ни одного бренд-сигнала; первичные кнопки, фокус, ссылки и активная навигация выглядят одинаково монохромно.
- Шрифт фактически не загружался: токен `--font-sans` указывал на `Roboto`, но `@fontsource/roboto` + `unplugin-fonts` были удалены в Фазе 2.9 — работал системный fallback.
- Не было системных паттернов для loading / empty состояний и быстрой навигации (command palette).

Дизайн-ревью зафиксировало направление: сдержанный продуктовый стиль уровня Linear/Vercel — нейтральная база + **один** акцент, современная типографика, иерархия через whitespace и контраст поверхностей, а не через рамки.

## Decision

1. **Шрифт — self-hosted Inter Variable** (`@fontsource-variable/inter`, импорт в [src/app/main.ts](../../src/app/main.ts)). Без внешних запросов к Google Fonts и без FOUC. `--font-sans` = `'Inter Variable', …`. В `@layer base` — font-smoothing, OpenType-фичи, `letter-spacing: -0.015em` для `h1-h3`.
2. **Нейтральная база + индиго-акцент.** `--primary` остаётся нейтральным (первичные кнопки нейтральные). Введён токен `--brand` (indigo-600 в light, indigo-400 в dark) + `--brand-foreground`, зарегистрирован в `@theme` → утилиты `bg-brand` / `text-brand`. `--ring` переведён на brand (брендовый фокус по всему UI). Бренд живёт на: фокусе, ссылках, активной навигации, tonal-действиях.
3. **WCAG 2.1 AA.** Каждая пара токенов проверяется на контраст (текст ≥ 4.5:1, UI ≥ 3:1) в обеих темах; смысл не передаётся только цветом (активный пункт = brand + вес шрифта). `--muted-foreground` поднят до zinc-600 ради AA.
4. **Примитивы и паттерны.** `Skeleton` / `EmptyState` / `PageHeader` в [shared/ui/base](../../src/shared/ui/base/) как единый паттерн состояний; командная палитра ⌘K (`CommandPalette` + [widgets/app-command-palette](../../src/widgets/app-command-palette/)).

Источник истины для цветов/типографики/spacing — токены в [src/shared/assets/tokens/](../../src/shared/assets/tokens/). Смена бренда = правка токенов, Tailwind подхватывает через `@theme`.

## Consequences

- **+** Узнаваемый, но сдержанный стиль; единый бренд-сигнал; современная типографика без внешних зависимостей рантайма.
- **+** Переиспользуемые примитивы состояний и быстрый доступ к навигации (power-user).
- **+** Ребрендинг локализован в токенах.
- **−** Авторы новых экранов обязаны держать дисциплину: акцент только на интерактиве, никаких локальных hex — всё через токены и обёртки.
- **−** Bundle включает woff2-сабсеты Inter (latin/latin-ext/cyrillic/greek) — десятки КБ, кэшируются.

Не отменяет [ADR-0007](0007-ui-stack-migration-from-vuetify.md) (стек), а уточняет визуальный язык поверх него.
