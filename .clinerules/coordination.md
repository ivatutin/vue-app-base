# Координация: где искать и как писать

> Файл проекта: Cline подхватывает правила автоматически, поэтому путь координации не нужно повторять в каждом промпте.
> Источник правил — `c:\vim\prj\video-service\docs\shared\conventions.md` (если доступен).

## Где координация

- Корень: **`c:\vim\prj\video-service`** (вне этого репозитория).
- Наш канал: `…\docs\auth\sessions\vue-app-base\questions\` — пишем **мы**; ответы — `…\replies\`;
  материалы нам — `…\handover\`.
- Зеркало контракта: `…\docs\auth\contract.sha256` (свою копию `docs/auth-v1-contract.md` сверяем, не правим).

## Шаг 0 — проверка канала (обязательно, до начала любой работы)

```powershell
Test-Path 'c:\vim\prj\video-service\docs\auth\sessions\vue-app-base\questions'
```

- **True** → работаем по обычной схеме (файлы в координацию).
- **False** → канал недоступен (окружение ограничено репозиторием). **Не работать «вслепую»**:
  1. писать в `docs/coordination/questions/<тема>.md` **этого** репозитория;
  2. сразу сказать в чате: «координатор недоступен, пишу в локальный outbox»;
  3. ответы читать в `docs/coordination/replies/`.

## Правила (коротко)

1. **Отчёт — это файл, не сообщение коммита.** Коммит не читается как переписка; свести туда отчёт — значит потерять канал.
2. Шапка файла: `Кому / От кого / Дата / Статус` (`вопрос` → `отвечено` → `принято`).
3. Статус в файлах `questions/` переключает **координатор**; мы файл больше не правим.
4. Материал для другой сессии — только через координатора (прямая переписка сессий запрещена).
5. Внешние пути (координация) — **только чтение/запись переписки**; код живёт только в этом репозитории.
